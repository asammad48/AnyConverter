# Phase 06: Product Expansion And Authority

Timeline from report: Weeks 6-8

## Objective

Build tools that strengthen the core clusters and create reasons for others to link to AnyConverter. The report advises against adding more unrelated generic utilities.

## Source Basis

Drawn from these report sections:

- Keyword and low-competition product opportunities
- New frontend-only tools I would build
- Prioritised backlog
- The decision rule for new tools
- Final assessment and limitations

## Product Decision Rule

Build a new tool only when it passes all five checks:

```text
Search intent exists
Competition is realistically beatable
It fits one of the authority clusters
It can genuinely run frontend-only
AnyConverter can make it meaningfully better or more private
```

## Recommended Tools

Strong cluster-fit candidates from the report:

- EXIF viewer/remover
- PDF metadata remover
- HAR analyzer
- JSON to TypeScript/Zod
- Unicode inspector/normalizer
- CSV diagnostics tools
- Cron visualizer

## Deprioritized Work

Avoid for now:

- More generic calculators
- More clocks
- Random novelty pages
- Mass language expansion
- Tools that require backend uploads but are marketed as private/local

## Authority Work

The report identifies authority/backlinks as a bottleneck. Start with a linkable technical asset around the site's strongest differentiator:

- How local browser-based file processing works
- Privacy comparison of uploaded vs local PDF/image tools
- Technical explanation of no-upload PDF/image workflows
- Security limitations of visual PDF blackout vs true redaction

Then start editorial outreach to relevant publications, privacy communities, developer newsletters, and web utility roundups.

## Checks

- New tool belongs to PDF, Developer/Data, or Browser/Device.
- Tool can run in-browser without contradicting privacy claims.
- Tool page includes unique examples, constraints, and troubleshooting.
- Tool has a clear internal linking path from its hub.
- Analytics events measure starts, success, errors, and downloads/copies.
- Linkable asset is useful without needing inflated SEO copy.
- Outreach targets are relevant and legitimate.

## Deliverables

- New-tool scoring sheet using the five-question rule.
- First privacy/product expansion tool shipped or scoped.
- Linkable technical asset outline or draft.
- Editorial outreach target list.
- Internal link updates for new tools.

## Exit Criteria

Move to Phase 07 when:

- Product expansion reinforces core authority rather than broadening randomly.
- At least one high-fit privacy/developer tool is shipped or ready.
- Authority work has started with a real asset, not purchased or low-quality links.
