# Project Memory — AnyConverter

## 1. Project Context
- **Name:** AnyConverter
- **Repository:** https://github.com/asammad48/AnyConverter
- **Core Technology:** HTML5, Modern Vanilla JavaScript (ES6+), Tailwind CSS / Custom CSS, Web Workers for client-side processing, Canvas / Web APIs.
- **Hosting / Infrastructure:** Cloudflare Pages / Workers static deployment.

## 2. Strategic Objectives
- Autonomous SEO auditing and indexing optimization across all tool and calculator subdirectories.
- Keyword and competitor gap analysis using DataForSEO and Google Search Console.
- Consistent, modern, accessible UI/UX redesign across hundreds of client-side web tools.
- Strict automated regression testing using Playwright and Chrome DevTools MCP.
- Systematic authority research and backlink prospect discovery without automated spam.

## 3. Scope of Tools & Directory Architecture
AnyConverter hosts over 70+ standalone, client-side browser utilities categorized into:
- **PDF Tools:** `compare-pdf`, `crop-pdf`, `unlock-pdf`, `add-watermark`, `add-page-numbers`, etc.
- **Converters & Encoders:** `color-converter`, `currency-converter`, `base64-encoder`, `url-encoder`, `csv-to-sql`, `camt053-to-csv`, `xml-formatter`.
- **Calculators:** `bmi-calculator`, `calorie-calculator`, `age-calculator`, `compound-interest-calculator`, `aspect-ratio-calculator`, `unit-price-calculator`, `birthday-countdown-calculator`.
- **Generators & Utilities:** `barcode-generator`, `css-gradient-generator`, `css-shadow-generator`, `uuid-generator`, `character-counter`, `word-counter`, `typing-speed-test`, `webcam-tester`, `world-clock`, `countdown-timer`.

## 4. Key Performance Indicators (KPIs)
- **Technical SEO:** 100/100 Lighthouse SEO score, zero broken canonicals, comprehensive JSON-LD schema on all tool pages.
- **Core Web Vitals:** LCP < 2.0s, CLS < 0.05, INP < 150ms on mobile & desktop.
- **Organic Visibility:** Improved average ranking positions and impressions across primary tool search queries.
