Cómo Generar Códigos de Barras

  1. Elige Uno para un solo código, o Lista para pegar muchos valores a la vez (uno por línea).
  2. Elige el tipo de código. Code 128 acepta cualquier texto; EAN-13, UPC-A y Code 39 tienen reglas específicas que se comprueban automáticamente.
  3. Descarga el código como SVG o PNG, o usa "Imprimir hoja" para imprimir una página de códigos directamente.

Qué tipo de código de barras debo usar

Code 128 codifica cualquier texto ASCII de forma compacta y no requiere registro, por lo que es la opción por defecto para SKU internos, etiquetas de activos y envíos. EAN-13 es el estándar para productos de venta en toda Europa (incluida España); UPC-A es su equivalente en EE. UU./Canadá. Code 39 es un formato más antiguo que aún se usa en algunos sistemas industriales, de automoción y de tarjetas de identificación.

El dígito de control de EAN-13/UPC-A, explicado

El último dígito de un número EAN-13 o UPC-A no es arbitrario: se calcula a partir de los demás dígitos para que un escáner (o una persona) pueda detectar un número mal escrito. Esta herramienta lo calcula automáticamente cuando lo omites, y lo valida cuando proporcionas el número completo, así nunca generas un código que se lee como el código de producto equivocado.

¿Necesito un número licenciado por GS1?

Técnicamente puedes generar aquí cualquier número EAN-13 o UPC-A, pero las tiendas solo aceptan números licenciados por GS1 en tu país (GS1 España, etc.) — de lo contrario, el número podría pertenecer ya al producto de otra empresa. Para uso interno (inventario, bibliotecas, eventos, seguimiento de activos), Code 128 no requiere ningún registro.

Preguntas Frecuentes

¿Puedo crear muchos códigos de barras a la vez? +
Sí. Cambia al modo Lista y pega un valor por línea (opcionalmente con un texto tras un tabulador), y se generan todas las líneas a la vez.
¿Qué hace el dígito de control? +
Los códigos EAN-13 y UPC-A terminan con un dígito de control calculado a partir de los demás dígitos. Si lo omites, se añade automáticamente; si introduces el número completo con el dígito incorrecto, un error indica cuál debería ser.
¿Qué tipo de código de barras debo usar? +
Code 128 codifica cualquier texto y no requiere registro, por lo que es ideal para etiquetas internas. EAN-13 y UPC-A son para productos de venta al público en Europa y EE. UU./Canadá respectivamente. Code 39 es un formato más antiguo que aún se usa en algunos sistemas industriales y de identificación.
¿Puedo usar cualquier número EAN-13 o UPC-A en productos reales? +
Solo para uso interno. Para vender a través de tiendas necesitas un número licenciado por GS1 en tu país.
¿Se suben mis datos? +
No. Los códigos se generan totalmente en tu navegador.
