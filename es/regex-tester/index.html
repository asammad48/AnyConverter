Cómo funciona: Motor RegExp de ECMAScript y evaluación de patrones

¿Qué es un verificador de expresiones regulares?

Un verificador de expresiones regulares es una herramienta interactiva de depuración que compila patrones de búsqueda en texto de prueba mediante el motor nativo ECMAScript RegExp del navegador, capturando grupos y calculando desplazamientos de coincidencia en tiempo real. Permite inspeccionar coincidencias, comprobar límites y validar reglas de extracción complejas.

Cómo funciona en el navegador

Nuestro banco de pruebas compila patrones en el entorno local del navegador utilizando los motores estándar V8 o SpiderMonkey para garantizar paridad exacta con JavaScript:

  1. Compilación con motor ECMAScript RegExp y flag handling: El patrón se instancia mediante new RegExp(pattern, flags) bajo el motor ECMAScript RegExp engine, admitiendo flag handling para las banderas global (g), insensible a mayúsculas (i), multilínea (m), dotAll (s) y unicode (u).
  2. Captura de grupos (match group capturing): El motor recorre el texto ejecutando match group capturing para grupos de captura numerados y con nombre, calculando índices de inicio y fin.
  3. Resaltado visual no destructivo: Los fragmentos coincidentes se delimitan mediante etiquetas de marcado con colores contrastados para distinguir coincidencias consecutivas.
  4. Protección de ejecución: La evaluación se ejecuta con límites de seguridad para proteger el navegador frente a bloqueos por retroceso catastrófico (catastrophic backtracking).

Especificaciones técnicas y estándares del motor

El verificador opera bajo la especificación oficial ECMAScript RegExp (ECMA-262) engine. Es compatible con aserciones anticipadas (lookahead) y retrospectivas (lookbehind), match group capturing avanzado ((?<nombre>...)), riguroso flag handling, escapes de propiedades Unicode (\p{...}) y retro-referencias, ejecutándose enteramente en tu equipo con privacidad absoluta.

Preguntas Frecuentes

¿Qué sabor de regex se usa? +
La herramienta usa el motor de regex de JavaScript, que es compatible con ECMA-262. Es el mismo motor que usan Node.js y los navegadores modernos.
¿Qué significan los flags? +
g (global) encuentra todas las coincidencias en lugar de solo la primera. i ignora mayúsculas y minúsculas. m trata cada línea como una cadena separada para ^ y $. s hace que el punto (.) coincida también con saltos de línea.
