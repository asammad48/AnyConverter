Como usar Notas Adhesivas

  1. Elige un color de nota con los circulos de color.
  2. Haz clic en Anadir nota, o pulsa N cuando no estes escribiendo en un campo.
  3. Escribe en la tarjeta. La nota se guarda automaticamente en este navegador.
  4. Usa fijar, cambiar color, copiar, eliminar, deshacer, buscar, filtros, exportar e importar cuando el tablero crezca.

Caracteristicas

  • Seis colores con estado seleccionado claro
  • Guardado automatico solo en este navegador
  • Las notas fijadas permanecen arriba
  • Busqueda y filtros de color cuando existen notas
  • Deshacer eliminacion, copiar, exportar TXT/JSON, importar JSON y copiar como lista

Notas adhesivas online para planificacion rapida

Usa notas adhesivas online gratis cuando necesites un tablero privado en el navegador para recordatorios, ideas, listas, reuniones y planificacion. Las notas se guardan localmente y cubren busquedas como notas online, notas adhesivas y tablero de notas sin crear cuenta.

Por que ayuda

  • Ideal para: recordatorios, ideas, borradores, notas de reunion, compras y sesiones cortas de planificacion.
  • Privacidad: las notas se quedan en este navegador mediante almacenamiento local y no se suben a AnyConverter.
  • Siguiente paso: exporta tus notas antes de cambiar de dispositivo o borrar datos del navegador.

Preguntas Frecuentes

Son privadas mis notas? +
Si. Las notas se guardan solo en este navegador con almacenamiento local. No se suben a los servidores de AnyConverter.
Puedo hacer una copia de seguridad? +
Si. Usa la tarjeta de copia de seguridad para descargar TXT o JSON. Puedes importar el JSON mas tarde para unir las notas al tablero.
Puedo organizar notas por color? +
Si. Elige un color antes de anadir una nota y usa el boton de color en cada nota para cambiarlo. Cuando hay notas, aparecen filtros por color.
