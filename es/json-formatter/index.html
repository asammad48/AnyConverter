Cómo formatear JSON

  1. Pega tu JSON — Copia tu JSON y pégalo en el área de entrada. La salida se formatea automáticamente mientras escribes.
  2. Explora el árbol — Haz clic en los iconos ▾ para contraer o expandir cualquier objeto o array. Usa Contraer todo / Expandir todo para navegar por estructuras grandes.
  3. Copia o descarga — Copia la salida formateada al portapapeles o descárgala como archivo .json.
  4. Busca o guarda un marcador — Usa el panel lateral para buscar claves, valores, con regex o una ruta como a.b[0].c, o guarda el JSON actual como marcador local.

Características

  • Autoformato en vivo mientras escribes (retardo de 200ms)
  • Nodos plegables — contrae cualquier {} o [] al instante
  • Resaltado de sintaxis con tokens codificados por color
  • Validación de JSON con la posición exacta del error
  • Minifica JSON para reducir el tamaño del archivo
  • Sube archivos .json directamente
  • Descarga la salida formateada como .json
  • Exportación a YAML y conversión a CSV para formas de JSON compatibles
  • Busca por clave, valor, regex o ruta con coincidencias resaltadas
  • Marcadores locales — guarda fragmentos de JSON en tu navegador para más tarde

Formateador JSON: usos prácticos

Usa formateador JSON cuando necesites una respuesta rápida, clara y privada sin crear una cuenta. La página también cubre variantes relacionadas como embellecer JSON, validar JSON, formato JSON online para que puedas elegir el flujo correcto.

Cuándo usarlo

  • Ideal para: Pegar código, datos estructurados, tokens, hashes o texto codificado y obtener un resultado claro al instante.
  • Detalles útiles: Usa ejemplos, mensajes de validación, acciones de copia y opciones de formato para detectar errores antes de publicar.
  • Siguiente paso: Continúa con otro formateador, validador, codificador, parser o convertidor cuando cambie el formato de trabajo.

Preguntas Frecuentes

¿Qué es un formateador JSON? +
Un formateador JSON analiza JSON en bruto o minificado y lo vuelve a escribir con sangría y saltos de línea legibles.
¿Puede esta herramienta validar JSON? +
Sí. La página analiza tu entrada con JSON.parse y muestra un mensaje de error de sintaxis cuando el JSON no es válido.
¿Puedo convertir JSON a CSV? +
La conversión a CSV funciona cuando el JSON es un objeto o un array de objetos. Otras formas de JSON deben mantenerse en formato JSON o YAML.
¿Qué es la minificación de JSON? +
La minificación elimina espacios y saltos de línea innecesarios del JSON válido, conservando los datos analizados.
¿Qué tipos de archivo puedo subir? +
Puedes subir un archivo .json con el botón Subir. El archivo se carga en el área de entrada para formatear o validar.
¿Cómo funciona la búsqueda en JSON? +
Busca en la clave, el valor o ambos, con texto simple, expresiones regulares o una ruta con puntos/corchetes como a.b[0].c. Las coincidencias se resaltan y puedes navegar entre ellas con los botones Anterior/Siguiente.
¿Los marcadores se guardan en línea? +
No. Los marcadores se guardan solo en el almacenamiento local de tu navegador, por lo que permanecen en este dispositivo y nunca se suben.
