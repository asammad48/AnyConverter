How to Set PDF Permissions

  1. Upload your PDF.
  2. Set an owner password (required) and optional user password.
  3. Tick or untick the permissions you want to allow.
  4. Click "Apply Security & Download".

Features

  • Owner password required to change permissions
  • Optional user password to restrict opening
  • Permission controls for print, copy, modify, annotate, and fill forms
  • Rebuilds the secured PDF with pdf-lib in the browser tab
  • Viewer enforcement can vary, so test the downloaded file

PDF Security: passwords and viewer permissions

Use PDF Security when you need to save a PDF with an owner password, optional open password, and permission settings for common viewer actions. The tool copies the PDF pages into a new secured file and downloads it as secured.pdf.

Example workflow

Upload a draft PDF, enter an owner password, choose whether viewers can print or copy content, and download the secured PDF. Open the result in the PDF viewers your audience uses to confirm the permissions behave as expected.

Limits to check

  • Owner password: Required before the page can apply the permission settings.
  • Viewer behavior: PDF permissions are interpreted by the app that opens the file and should be tested before sharing.
  • Not redaction: This tool does not remove sensitive text, images, or hidden PDF objects from the document.

Frequently Asked Questions

What is the difference between an owner and a user password? +
The user password is required to open the PDF. The owner password is required to change permissions or remove restrictions. Both are set here; only the owner password is mandatory.
Do PDF permissions work in every viewer? +
PDF permissions can depend on the app used to open the file. Test the secured PDF in the viewers your audience uses before relying on print, copy, edit, annotation, or form restrictions.
Can PDF Security remove sensitive content? +
No. PDF Security sets passwords and permissions; it does not remove text, images, or hidden PDF objects. Remove sensitive content with appropriate redaction software before sharing confidential files.
