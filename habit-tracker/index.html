Habit Tracker Online

Build and maintain daily habits with a visual weekly grid. Track streaks, see your completion rate for the week and stay consistent.

How to Use the Habit Tracker

  1. Type a habit name and click Add Habit.
  2. Click the circle for each day you completed the habit this week.
  3. Watch the streak counter grow with consecutive daily completions.
  4. Delete a habit with the × button on the right.

Features

  • Weekly grid (Mon–Sun) for the current week
  • Streak counter — tracks consecutive days
  • Done/7 counter for weekly completion rate
  • Today's date is highlighted with a ring
  • Data persists in localStorage between visits

Build a Simple Weekly Habit System

This habit tracker works best for small daily routines where consistency matters more than complexity: drinking water, reading, stretching, studying, journaling, exercise, or sleep habits.

Tips for better streaks

  • Track habits you can complete in a clear yes-or-no way.
  • Start with three to five habits instead of filling the board immediately.
  • Review the weekly grid with a daily planner or to-do list when planning tomorrow.

For focused work sessions, pair this tracker with the Pomodoro timer and use sticky notes for quick reminders.

Frequently Asked Questions

Does it track habits across multiple weeks? +
Yes. The check data is stored by date, so you can always come back and it will show the correct week. The display always shows the current week, and the streak counts consecutive days going back from today.
Can I mark past days as done? +
Yes. Click any day circle — including past days — to toggle it on or off. The streak will be recalculated from today backwards.
