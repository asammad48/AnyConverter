    How to Merge PDF Files

    1. Add your PDF files — Drop multiple PDFs onto the upload area or click to select them from your device.
    2. Reorder if needed — Drag files in the list to change the order they'll appear in the merged document.
    3. Click Merge PDFs — Download the combined PDF file instantly.

    Features

    • Requires two or more PDF files
    • Drag to reorder before merging
    • Optional alphabetical sort and blank separator pages
    • Custom output filename
    • Shows total file size estimate
    • Powered by pdf-lib

    Merge PDF online with order controls

    Use Merge PDF to combine two or more PDF files into one document. The page copies every page from each selected PDF into a new PDF document, then saves the result as a downloadable file.

    Example workflow

    • Packet assembly: Upload a cover sheet, a signed agreement, and appendix PDFs, then drag the cover sheet to the top.
    • Section breaks: Turn on blank separators when you want visual breaks between source documents.
    • Limits: Encrypted, malformed, or very large PDFs may fail before the download is created.

    For related workflows, try Split PDF for page extraction, Organize PDF for page-level ordering, or Compress PDF Online after merging.

    Frequently Asked Questions

    Is there a file size limit? +
    The page does not set a fixed file size limit, but very large PDFs or large batches can fail if the browser runs out of memory.
    How many PDFs do I need? +
    At least two PDF files are required before the merge button can create an output document.
    Can I merge password-protected PDFs? +
    Encrypted, password-protected, or damaged PDFs may not load in the browser merge process.
    Can I pick page ranges from each PDF? +
    This page merges whole PDF files. Use Split PDF or Organize PDF first if you need page-level selection or ordering.
    What output file is downloaded? +
    The tool creates a new PDF from the uploaded documents and downloads it as merged.pdf unless you enter a different filename.
