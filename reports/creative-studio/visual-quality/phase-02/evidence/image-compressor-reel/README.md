# Image Compressor reel

[Finished MP4](AnyConverter-Image-Compressor-Reel.mp4) · [Cover](AnyConverter-Reel-Cover.png) · [Measured result](measurements.json)

The 18-second, 1080 × 1920 reel uses titles, captions and backing audio exported through Creative Studio. The sample photo was AI-generated. The screenshots and compressed WebP came from a real local run of the AnyConverter Image Compressor. The tool measured 3.01 MB to 308.4 KB at 80% WebP quality.

The photo and screenshots were composited with FFmpeg after the Studio export. The included Studio archive contains the editable base sequence. The finished MP4 contains the external compositing.

| File | Contents |
|---|---|
| `sample-alpine-lake.png` | AI-generated input photo |
| `compressed.webp` | Compressor download |
