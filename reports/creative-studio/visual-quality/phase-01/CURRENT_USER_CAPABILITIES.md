# Phase 01 — Current User Capabilities & Editing Boundaries Report

**Project:** AnyConverter Creative Studio — Visual Quality Production Programme  
**Phase:** 01 (Visual Baseline, Canonical Compositor & First Publishable Slice)  
**Document Purpose:** Frank, unambiguous documentation of what an ordinary user can produce through the AnyConverter website today, what is restricted to pre-authored presets, and what is deferred to later phases.

---

## 1. Direct Answers to the Seventh Audit Questions

| Audit Question | Current Status in Phase 01 | Technical Reality & Dependency |
|---|---|---|
| **Can users replace the character?** | **NOT IMPLEMENTED** | The character (Mr. Cockatoo) is a hard-coded procedural Canvas function in `reference-shot.js` (`_renderCharacterComedy`). No UI control exists to select an alternative character or upload a character sprite. Deferred to **Phase 04 (Character & Vector Asset Pipeline)**. |
| **Can users alter character poses?** | **NOT IMPLEMENTED** | Poses (`neutral`, `wing-point`, `shocked`, `smug`) are hard-coded to fixed frame ranges in `reference-shot.js`. The user cannot manually keyframe, select, or trigger poses. Deferred to **Phase 04 (Rigging & Pose Interpolation)**. |
| **Can users create a new character?** | **NOT IMPLEMENTED** | There is no character creator, vector path editor, or avatar designer in the website. Deferred to **Phase 04 / Phase 10**. |
| **Can users upload & position images in video shots?** | **NOT IMPLEMENTED** | Image upload exists in 2D graphic mode via `#cs-btn-add-image`, but is **not** integrated into the video shot compositor. Deferred to **Phase 02 / Phase 06 (Asset Track Integration)**. |
| **Can users create, delete, or reorder video shots?** | **PENDING OWNER DECISION** | In video mode, shot sequences are fixed-length arrays generated by preset factories (5 shots for SaaS, 1 shot for pilots). Reordering/replacing shots requires an owner decision between **Choice A** (minimum 5-shot swap in Phase 01) or **Choice B** (deferring comprehensive multi-clip timeline editing to **Phase 10, WP2**, as Phase 02 is Design Tokens & Grids). |
| **Can users choose an arbitrary new background?** | **NOT IMPLEMENTED** | Backgrounds (radial glows, tech grids, noir corridor) are hard-coded in the renderer. There is no background color/image picker for video scenes. Deferred to **Phase 02**. |
| **Can users modify camera motion paths?** | **NOT IMPLEMENTED** | Camera moves (push-in, whip-in, pan) are preset per shot in `creative-director.js`. There are no camera controls exposed to users. Deferred to **Phase 02 / Phase 09**. |
| **Can users edit copy and narrative text?** | **IMPLEMENTED** | Any user can freely edit the Headline (`#cs-shot-headline`) and Narrative Subhead (`#cs-shot-subhead`) for every shot in the sequence via standard UI form inputs. |
| **Can users customize brand accent colors?** | **IMPLEMENTED** | Any user can pick an Accent Color (`#cs-shot-accent`) per shot, dynamically retinting badges, text highlights, progress bars, and props. |
| **Can users adjust shot timing and durations?** | **IMPLEMENTED** | Any user can change Duration (`#cs-shot-duration`) in frames for each shot, automatically recalculating the full timeline length and playhead boundaries. |
| **Can users reorder shots in the sequence?** | **IMPLEMENTED** | Any user can reorder the five shots using Move Up (`#cs-btn-shot-move-up`) and Move Down (`#cs-btn-shot-move-down`) in the inspector, or direct ▲/▼ buttons on `#cs-shots-list`. Complete shot objects (id, headline, subhead, duration, visual motif, brand mode, accent, animation parameters) move with immediate sequential recalculation of timeline start frames and total duration. Boundary buttons are strictly disabled. Reordering is 100% preserved across art directions, `.acstudio` archives, and WebM exports. |
| **Can users preview their edits with audio?** | **IMPLEMENTED** | Users can scrub the timeline ruler (`#cs-timeline-scrubber`) or hit Play (`#cs-btn-play-pause`) to see 100% state-matched Canvas rendering with Web Audio synthesis. |
| **Can users export video client-side?** | **IMPLEMENTED** | Clicking `#cs-btn-export-video` renders a deterministic WebM video file directly in the browser via WebCodecs and triggers an automatic browser download. |
| **Can users save and reopen projects?** | **IMPLEMENTED** | Clicking `#cs-btn-save-project` downloads an `.acstudio` ZIP archive. Clicking `#cs-btn-open-project` unzips and fully restores all customized titles, shots, copy, accents, and durations. |

## 5. Phased Roadmap: Honest Classification of Deferred Features

| Feature | Phase 01 Status | Scheduled Delivery Phase | Architectural Scope |
|---|---|---|---|
| **Template-based Vertical Slice** | **DONE (PASS)** | Phase 01 | 3 preset directions, text editing, accent color, duration, WebM export, .acstudio save/reopen. |
| **Five-Shot Reordering via UI** | **DONE (PASS)** | Phase 01 | Move Up / Move Down controls in inspector and shot list; swaps complete shot objects, recalculates timing, preserved across export/archive. |
| **Advanced Non-Linear Timeline (Arbitrary tracks, drag-and-drop, clip splitting)** | **SCHEDULED** | Phase 10 (WP2) | Freeform multi-track editing, arbitrary shot insertion/deletion, drag-and-drop sequencing, audio ripple editing. |
| **Background & Lighting Selector** | **DEFERRED** | Phase 02 | User selection of background gradients, image backdrops, and lighting temperature presets. |
| **Asset Library Video Integration** | **DEFERRED** | Phase 02 / Phase 06 | Drag-and-drop user raster images (PNG, JPEG, WebP) and logos into video shot containers. |
| **Character & Vector Rigging Pipeline** | **DEFERRED** | Phase 04 | Character designer, swappable character bodies, custom pose keyframing, and speech syncing. |
| **Cinematic Motion & Spline Camera** | **DEFERRED** | Phase 09 | User-configurable 3D spline camera trajectories (dolly, crane, tracking shot). |
| **Multi-Character Dialogue Engine** | **DEFERRED** | Phase 10 | Staging 2+ characters with alternating comic speech balloons and reaction poses. |
| **Prompt-to-Video Story Compiler** | **DEFERRED** | Phase 12 | Natural language prompt compiling into a multi-shot sequence with automated copy and scene selection. |

## 6. Truth Gate Conclusion & Governance

1. **Acceptance as a Template Slice:** Phase 01 succeeds as an initial high-performance, client-side template editing slice. Users can author distinct, coherent video messages (as demonstrated in the Password Vault explainer) by customizing pre-authored shot structures.
2. **Rejection of Premature General Creation Claims:** Phase 01 must **not** be marketed as an arbitrary prompt-to-video generator, custom character designer, or full-featured non-linear video editor. Those capabilities belong strictly to subsequent phases.
3. **Verification Integrity:** The positive runner has been hardened to verify freshly exported video files directly, eliminating the retained-master bypass.
