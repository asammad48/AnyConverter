Why a rotated PDF sometimes opens sideways again

Turning a page in a PDF reader usually only changes how you see it on screen. When you close the file, the rotation is gone. This tool saves the rotation inside the PDF, so it opens the right way for everyone.

Each page stores its own rotation. Make all portrait checks every page and turns only the ones that are wider than they are tall.

Frequently asked questions

How do I rotate only one page?

Click that page. Each click turns it another 90° clockwise.

Will rotating reduce quality?

No. Only the rotation setting of each page changes.

Is the rotation saved?

Yes. It is stored in the new PDF, so it opens the right way in any app.

Is my file uploaded?

No. Everything happens in your browser.
