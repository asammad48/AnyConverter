What happens when PDFs are merged

Each page is copied into the new file exactly as it was: text stays selectable, links keep working and images are not recompressed. So the merged file is roughly the size of the originals added together.

Fillable form fields and bookmarks from the original files may not carry over. If you need a form to stay fillable, fill it in and save it first, then merge. Password-protected PDFs need to be unlocked before they can be merged.

Frequently asked questions

How many PDFs can I merge at once?

There is no fixed limit. Very large jobs, like hundreds of scanned pages, depend on how much memory your device has.

Are my files uploaded anywhere?

No. The files are read and combined in your browser, so nothing is sent to our servers.

Can I merge only some pages of a PDF?

Yes. Open the file in the list and click the pages you want to leave out. They are skipped in the merged file.

Will the quality change?

No. Pages are copied as they are, without recompressing images or turning text into pictures.

Why did a blank page appear in my merged PDF?

You turned on double-sided printing. A blank page is added after any file with an odd number of pages, so the next file starts on a new sheet.
