Which barcode type should I use?

Code 128 encodes any ASCII text compactly and needs no registration, which makes it the default choice for internal SKUs, asset tags, and shipping labels. EAN-13 is the standard for retail products across Europe (including Denmark and Spain); UPC-A is its US/Canada equivalent. Code 39 is an older format still used in some industrial, automotive, and ID-card systems.

The EAN-13/UPC-A check digit, explained

The last digit of an EAN-13 or UPC-A number isn't arbitrary — it's calculated from the other digits so a scanner (or a human) can catch a mistyped number. This tool computes it for you automatically when you leave it off, and validates it when you provide the full number, so you never generate a barcode that reads back as the wrong product code.

Do I need a GS1-licensed number?

You can technically generate any EAN-13 or UPC-A number here, but retailers only accept numbers licensed from GS1 in your country (GS1 Denmark, GS1 Spain, GS1 US, and so on) — otherwise the number may already belong to someone else's product. For internal use — inventory, library systems, events, asset tracking — Code 128 needs no registration at all.

Frequently Asked Questions

Can I create many barcodes at once? +
Yes. Switch to List mode and paste one value per line (optionally with a caption after a Tab), and every line is generated at once.
What does the check digit do? +
EAN-13 and UPC-A barcodes end with a check digit computed from the other digits. If you enter the number without it, it is added automatically; if you enter a full number with the wrong check digit, an error explains what it should be.
Which barcode type should I use? +
Code 128 encodes any text and needs no registration, so it suits internal labels and asset tags. EAN-13 and UPC-A are for retail products in Europe and the US/Canada respectively. Code 39 is an older format still used in some industrial and ID systems.
Can I use any EAN-13 or UPC-A number on real products? +
Only for internal use. To sell through retailers you need a number licensed from GS1 in your country.

No. Barcodes are generated entirely in your browser.
