How to Encode or Decode a URL

  1. Choose mode — Select Encode Component for query parameters, Encode Full URL to preserve URL structure, or Decode to reverse encoding.
  2. Enter your text or URL — Paste the string you want to encode or decode into the input area.
  3. Click Convert — Copy the output or use Swap to move the output back to input for chaining.

Features

  • Encode URL components (encodeURIComponent)
  • Encode full URLs (preserves ://&=?#)
  • Decode percent-encoded URLs
  • Optional + for spaces during encoding
  • Swap input and output
  • Live conversion on input

URL encoder for components and full URLs

Use URL Encoder to prepare query parameter values, encode a full URL while preserving its structure, or decode percent-encoded text back into readable form.

Example workflow

  • Query values: Choose Encode Component before placing text inside a single query parameter.
  • Form-style spaces: Turn on Encode spaces as + when a target system expects plus signs in query strings.
  • Limits: Decode can fail on invalid percent escapes, and Full URL mode intentionally preserves URL syntax characters.

Frequently Asked Questions

What is URL encoding? +
URL encoding turns characters into percent-encoded sequences so they can be used safely in URL components, query values, or full URLs.
When should I use Encode Component vs Encode Full URL? +
Use Encode Component for a single parameter value because it encodes separators like / and ?. Use Encode Full URL when you want to keep URL separators intact.
What does plus-space mode do? +
Plus-space mode writes spaces as + during encoding, which is useful for form-style query strings. Decode mode also treats plus signs as spaces.
Can decoding fail? +
Yes. Decode mode can show an error when the input contains malformed or incomplete percent escapes.
Does Full URL mode encode everything? +
No. Full URL mode preserves URL syntax characters, while Component mode encodes more characters for parameter values.
