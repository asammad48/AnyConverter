Clean PDF document properties before sharing

A PDF can include document properties such as title, author, subject, keywords, creator software, producer software, and creation or modification dates. Use this PDF metadata remover when you want to inspect those common fields and clear selected values before sending a non-sensitive copy.

Example workflow

  • Draft cleanup: Remove an internal author name or draft title before sharing a public handout.
  • Software labels: Clear creator and producer fields if they are not useful for the recipient.
  • Date handling: Leave dates unchanged when accuracy matters, or use the optional reset when you need a neutral placeholder.

Important limits

This is not secure sanitization. It does not remove visible text, hidden objects, annotations, attachments, JavaScript, embedded files, or content covered by visual blackout boxes. For sensitive documents, use reviewed redaction and sanitization software before publishing.

Frequently Asked Questions

What PDF metadata can this remove? +
The tool targets common document properties such as title, author, subject, keywords, creator, and producer. Date fields can be reset to a neutral placeholder if selected.
Does this remove hidden PDF content? +
No. It is not hidden-content removal, attachment removal, secure sanitization, or redaction. It rebuilds pages and clears selected document property fields.
Are my PDF files uploaded? +
The tool reads the PDF selected in your browser tab and creates the cleaned download locally. It uses the browser File API rather than a server upload workflow.
