Blackout PDF

Cover text or images in your PDF with solid black rectangles. This is a visual blackout tool; it does not securely remove underlying PDF text or objects.

Drop your PDF here or click to browse

Add one or more blackout rectangles. Coordinates are in PDF points from the bottom-left corner of the page.

How to Black Out a PDF

  1. Upload your PDF. The first page dimensions are shown.
  2. Enter the page number, X/Y coordinates, width and height for each blackout area.
  3. Click "+ Add Blackout" to add it to the list. Repeat for more areas.
  4. Click "Apply Blackouts & Download".

Features

  • Add multiple blackout rectangles across PDF pages
  • Remove individual blackouts before applying
  • Coordinates in PDF points (origin bottom-left)
  • Blackouts are solid black rectangles drawn on the page
  • Rebuilds the PDF with pdf-lib in the browser tab
  • Not suitable for legal, compliance, or confidential redaction because underlying PDF content can remain recoverable

Blackout PDF: visual covers for non-sensitive drafts

Use Blackout PDF to cover non-sensitive PDF areas with solid black rectangles. This is visual blackout only: it does not securely remove underlying PDF text, images, or objects from the file.

Example workflow

For a draft screenshot-style PDF, enter the page number and rectangle coordinates to cover a visible note before sharing an informal copy. Do not use this output for legal, compliance, confidential, or irreversible redaction needs.

Limits to check

  • Recoverable content: This tool draws black rectangles; underlying PDF content can remain recoverable.
  • Coordinates: Enter X, Y, width, and height in PDF points from the bottom-left corner.
  • Appropriate use: Use specialist redaction software when hidden content must be permanently removed.

Frequently Asked Questions

How do I find the coordinates of content I want to black out? +
Use coordinates in PDF points from the bottom-left corner of the page. A PDF editor or a rendered page image can help you measure the X, Y, width, and height values before applying a blackout.
Is the underlying text truly removed? +
No. This tool draws opaque black rectangles over the content. It does not remove the underlying text from the PDF structure. For legally compliant redaction, specialist software that permanently removes content is required.
