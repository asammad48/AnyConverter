How to Optimize a PDF

  1. Upload your PDF.
  2. Optionally tick "Strip metadata" if you do not need document title, author, subject, or keyword fields.
  3. Click "Optimize & Download" and compare the measured output size.

Features

  • Rebuilds the PDF into a new file
  • Uses object streams for save output
  • Optional metadata clearing for title, author, subject, and keywords
  • Shows before and after file size comparison
  • Reports measured savings instead of estimating

Optimize PDF with measured results

Use Optimize PDF to rebuild a PDF and check whether the saved result is smaller. It is useful for files that have been edited many times, but it is not the same as guaranteed compression.

Example workflow

  • Edited document: Upload a PDF that has been saved repeatedly, turn on metadata cleanup if those fields are not needed, then compare the result.
  • Measured choice: Download the optimized file only after reviewing the displayed original and output sizes.
  • Limits: The tool does not downsample images, remove hidden content, or guarantee a smaller file.

For related workflows, try PDF Metadata Remover for a dedicated document-properties cleanup flow, Compress PDF Online for a simpler size-comparison flow, Merge PDF Files Online, or Organize PDF.

Frequently Asked Questions

How much will this reduce my PDF? +
It depends on the PDF. The page reports the measured original and optimized sizes, and some already-optimized files may show little or no reduction.
What metadata can be cleared? +
The optional cleanup targets document metadata fields such as title, author, subject, and keywords. It is not hidden-content removal or secure sanitization.
Does this downsample images? +
No. This browser-side optimizer rebuilds the PDF and uses save settings; it does not downsample or re-encode images.
