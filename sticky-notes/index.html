How to Use Sticky Notes

  1. Pick a note colour from the round swatches.
  2. Click Add note, or press N when you are not typing in a field.
  3. Type in the note card. Your note saves automatically in this browser.
  4. Use pin, colour, copy, delete, undo, search, filters, export, and import when your board grows.

Features

  • Six colour swatches with clear selected state
  • Auto-save notes in this browser only
  • Pinned notes stay at the top of the board
  • Search and colour filters appear when notes exist
  • Undo delete, copy note, export TXT/JSON, import JSON, and copy as checklist

Frequently Asked Questions

Are my notes private? +
Yes. Notes are stored only in this browser using local storage. They are never uploaded to AnyConverter servers.
Can I back up my sticky notes? +
Yes. Use the backup card to download notes as TXT or JSON. You can import a JSON backup later to merge notes back into the board.
Can I organize notes by color? +
Yes. Choose a swatch before adding a note, then use the color button on each note to cycle colors. When notes exist, color filters appear above the board.
