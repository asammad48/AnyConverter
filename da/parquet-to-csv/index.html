Sådan Konverterer Du Parquet til CSV

  1. Træk en .parquet-fil ind på siden, eller klik for at vælge en fra din computer.
  2. Tjek Forhåndsvisning- og Skema-fanerne for at bekræfte, at kolonnerne og dataene ser rigtige ud.
  3. Klik "Download CSV" for at gemme en Excel-klar CSV-fil — intet uploades på noget tidspunkt.

Funktioner

  • Læser Snappy-, Gzip-, Zstd- og Brotli-komprimerede Parquet-filer
  • 64-bit heltal konverteres til præcise cifferstrenge og afrundes aldrig via kommatal
  • Skema-fanen viser hver kolonnes navn og type direkte fra filens egne metadata
  • Indlejrede liste- og strukturkolonner skrives som JSON-tekst i CSV'en, så ingen data går tabt
  • Den danske og spanske side bruger som standard semikolon-adskilt CSV med decimalkomma og en UTF-8 BOM til Excel
  • Kører helt lokalt — ingen tilmelding, ingen filer sendes til en server

Hvad en Parquet-fil er

Apache Parquet er et kolonnebaseret, komprimeret og typet filformat brugt af Spark, Databricks, Snowflake-eksporter, AWS Athena/Glue, BigQuery-eksporter, pandas, Polars og DuckDB. Fordi data gemmes efter kolonne i stedet for række, komprimeres det godt og forespørges hurtigt — men det er ikke læsbart for mennesker, hvilket er hvorfor konvertering til CSV ofte er den hurtigste måde at åbne det i Excel eller en teksteditor.

Hvorfor decimaler og store ID'er går i stykker i andre konvertere

Parquet kan gemme 64-bit heltal, der er større end JavaScripts sikre heltalsområde, og DECIMAL-kolonner som skalerede heltal. En konverter, der læser disse gennem almindelige kommatal, ødelægger dem stille og roligt — et 19-cifret ID kan ende med at være ændret i de sidste cifre. Dette værktøj bevarer store heltal som præcise cifferstrenge i stedet for at sende dem gennem kommatal-matematik.

Åbning af CSV'en i Excel

Dansk Excel forventer en semikolon-adskilt CSV med komma som decimaltegn. Denne sides danske version bruger som standard semikolon/decimalkomma/BOM-kombinationen, der åbner korrekt uden en manuel importguide.

Til andre konverteringer af strukturerede data, prøv CSV til SQL, CSV Query eller JSON Formatter.

Ofte Stillede Spørgsmål

Bliver min Parquet-fil uploadet? +
Nej. Filen læses direkte af din browser, og CSV-filen laves på din egen enhed.
Hvorfor åbner min CSV som én kolonne i Excel? +
Dansk Excel forventer semikolon som skilletegn. Den danske side bruger som standard semikolon, decimalkomma og en UTF-8 BOM.
Hvad sker der med indlejrede liste- eller strukturkolonner? +
Lister og strukturer skrives som JSON-tekst i CSV-cellen, så data bevares, selvom de ikke deles ud i separate kolonner.
Bevares store tal og decimaler præcist? +
64-bit heltal konverteres som præcise cifferstrenge og ikke via kommatal, så store ID'er ikke afrundes.
Hvad er en Parquet-fil? +
Parquet er et kolonnebaseret, komprimeret og typet filformat brugt af bl.a. Spark, Databricks, BigQuery, pandas og Polars.
