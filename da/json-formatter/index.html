Sådan formaterer du JSON

  1. Indsæt din JSON — Kopiér din JSON, og indsæt den i inputfeltet. Output formateres automatisk, mens du skriver.
  2. Udforsk trævisningen — Klik på ▾-ikonerne for at folde et objekt eller array sammen/ud. Brug Fold alt sammen/Fold alt ud til at navigere i store strukturer.
  3. Kopiér eller download — Kopiér det formaterede output til udklipsholderen, eller download det som en .json-fil.
  4. Søg eller book mærke — Brug sidepanelet til at søge i nøgler, værdier, regex eller en sti som a.b[0].c, eller gem den nuværende JSON som et lokalt bogmærke.

Funktioner

  • JSON-validering med præcis fejlposition
  • Minificér JSON for at reducere filstørrelsen
  • Upload .json-filer direkte
  • Download formateret output som .json
  • YAML-eksport og CSV-konvertering for understøttede JSON-strukturer
  • Søg efter nøgle, værdi, regex eller sti med fremhævede resultater

JSON formatter: praktisk brug

Brug JSON formatter, når du har brug for et hurtigt, klart og privat resultat uden at oprette en konto. Siden dækker også relaterede behov som JSON validering, format JSON online, JSON beautifier, så du kan vælge den rigtige arbejdsgang.

Hvornår det er nyttigt

  • Bedst til: Indsætte kode, strukturerede data, tokens, hashes eller kodet tekst og få et læsbart resultat hurtigt.
  • Nyttige detaljer: Brug eksempler, valideringsbeskeder, kopieringshandlinger og formatering til at fange fejl tidligt.
  • Næste trin: Åben en relateret formatter, validator, encoder, parser eller konverter, når arbejdsgangen skifter format.

Fortsæt eventuelt med Online Regex Tester, Base64 Encoder og Decoder, Hash Generator, Unix Timestamp Konverter.

Ofte stillede spørgsmål

Hvad er en JSON-formatter? +
En JSON-formatter parser rå eller minificeret JSON og skriver den tilbage med læsbar indrykning og linjeskift.
Kan dette værktøj validere JSON? +
Ja. Siden parser din indtastning med JSON.parse og viser en syntaksfejlmeddelelse, hvis JSON'en er ugyldig.
Kan jeg konvertere JSON til CSV? +
CSV-konvertering fungerer, når JSON'en er et objekt eller et array af objekter. Andre JSON-strukturer bør forblive i JSON- eller YAML-output.
Hvad er JSON-minificering? +
Minificering fjerner unødvendige mellemrum og linjeskift fra gyldig JSON, samtidig med at de parsede data bevares.
Hvilke filtyper kan jeg uploade? +
Du kan uploade en .json-fil med knappen Upload. Filen indlæses i inputfeltet til formatering eller validering.
Hvordan fungerer JSON-søgning? +
Søg i nøglen, værdien eller begge med almindelig tekst, regex eller en sti som a.b[0].c adskilt med punktum/klammer. Resultater fremhæves, og du kan navigere mellem dem med knapperne Forrige/Næste.
Gemmes bogmærker online? +
Nej. Bogmærker gemmes kun i din browsers lokale lager, så de forbliver på denne enhed og uploades aldrig.
