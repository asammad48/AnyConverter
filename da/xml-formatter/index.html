Hvordan det virker: XML-parsing, DOM-serialisering og træ-formatering

Hvad er en XML-formaterer?

En XML-formaterer er et markup-værktøj, der analyserer extensible markup-dokumenter ved hjælp af browserens indbyggede DOMParser, validerer XML-velformethed i henhold til W3C-specifikationerne og serialiserer elementer i ensartede indrykningshierarkier (indentation hierarchies). Værktøjet genskaber komprimerede eller ustrukturerede XML-filer til overskuelige strukturer med bevarelse af attributter og tekstnoder.

Hvordan det virker i browseren

Vores formateringsmotor analyserer og strukturerer XML-dokumenter lokalt i browseren ved hjælp af standard XML-dokumentparsere uden eksterne biblioteker:

  1. W3C DOMParser-instantiering: XML-strengen parses via browserens indbyggede DOMParser med new DOMParser().parseFromString(xml, "application/xml") til en fuldstændig XML Document Object Model.
  2. Fejlfinding og velformethed: DOMParser opdager parsererror-noder ved uoverensstemmende tags eller ulovlige tegn og rapporterer præcise fejlmeddelelser.
  3. Rekursive indrykningshierarkier (indentation hierarchies): DOM-træet gennemgås rekursivt for at opbygge indentation hierarchies, beregne indlejringsniveauer og indsætte ensartede indrykninger (2 mellemrum, 4 mellemrum eller tabulator).
  4. CDATA & XML entity escaping: Tekstafsnit og CDATA-blokke bevares uden ændringer, og korrekt CDATA & XML entity escaping (&amp;, &lt;, &gt;, &quot;, &apos;) sikrer fuldkommen dataintegritet.
  5. Klientbaseret eksekvering: Behandlingen sker lokalt i browserens hukommelse uden overførsel til eksterne servere.

Tekniske specifikationer og W3C-standarder

Værktøjet overholder W3C XML 1.0 (Fifth Edition)-standarden og DOM Level 3 Core-specifikationerne. Gyldig XML kræver ét enkelt rodelement, strengt lukkede tags, case-sensitive elementnavne, velstrukturerede indentation hierarchies og præcis CDATA & XML entity escaping. Al formatering, komprimering og eksport udføres lokalt via DOMParser i din browsers hukommelse med 100% databeskyttelse.
