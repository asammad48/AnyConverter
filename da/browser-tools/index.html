Hardwarediagnosticering og browserbaserede testværktøjer

Fejlfind netværksforbindelse og test dit udstyr på sekunder. Mål internethastighed, kontroller responsive viewport-dimensioner, find døde skærmpixels og afprøv tastatur, mus, webcam og mikrofon.

Typiske anvendelsesmuligheder

  • Mål ping, download- og uploadhastighed på din internetforbindelse.
  • Find skærmens opløsning, aktive viewport-størrelse og pixelratio.
  • Find defekte eller fastlåste pixels på din computerskærm.
  • Test tastetryk, museknapper, scrollehjul, webcam og mikrofon i realtid.
