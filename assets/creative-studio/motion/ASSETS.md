# Motion showreel assets

The parrot atlas and SVG source are original artwork prepared for AnyConverter for Phase 04. The first row holds the body cels. The second row holds matching head cels around a neck pivot. The project archive embeds the PNG under its SHA-256 ID.

The envelope, inbox rows and noir compositions use the Studio's Canvas drawing code. The soundtrack uses the native Studio PCM synthesizer. Text uses the existing self-hosted fonts and their license notices.
