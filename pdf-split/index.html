How to Split a PDF

  1. Upload your PDF — Drop the PDF file or click to select it. The tool shows the total page count.
  2. Choose split mode — Extract specific pages by range, split every N pages, or extract each page individually.
  3. Download — Click Split PDF and download each resulting file.

Split PDF online by range or interval

Use Split PDF to create smaller PDF files from one source document. The page loads the PDF, copies the requested pages into new documents, and creates downloadable outputs with your chosen prefix.

Example workflow

  • Section extract: Upload a 30-page packet and enter 1-2, 9-14 to extract the cover and one section.
  • Batch output: Use every N pages for equal-sized parts, or each page for one file per page.
  • Limits: One source PDF is handled at a time, and browser memory limits apply for very large files.

Frequently Asked Questions

How do I specify page ranges? +
Use commas for individual pages and dashes for ranges. Example: 1,3,5-8,12 extracts pages 1, 3, 5, 6, 7, 8, and 12.
Can I extract just one page from a PDF? +
Yes. Use Extract pages mode and enter a single page number, such as 5, to create an output file with that page.
Can I download split files as a ZIP? +
Yes. Turn on the ZIP option when you want the split PDF files packaged together instead of downloaded individually.
What happens to duplicate page numbers? +
In page-range mode, valid page numbers are sorted and deduplicated before the output PDF is created.
Can I split a large PDF? +
The page does not set a fixed size limit, but encrypted, malformed, or very large PDFs can fail if they cannot be loaded in browser memory.
