How to Convert JPG to PDF

  1. Select one or more JPG or PNG images.

Features

  • Supports JPG, JPEG, and PNG images
  • Multiple images to one multi-page PDF
  • Three fit modes: original size, A4 keep ratio, fill A4
  • Configurable page margin
  • Creates image-based PDF pages

JPG to PDF converter with layout controls

Use JPG to PDF to turn photos, scans, or exported images into one PDF file. The converter embeds each selected image in a new PDF using the layout settings you choose.

Example workflow

  • Receipts: Select three receipt photos, choose A4, add a small margin, and download images.pdf for sharing or archiving.
  • Layout choice: Use original size for image dimensions, A4 fit for standard pages, or fill mode when page coverage matters more than preserving proportions.
  • Limits: Very large photos can be constrained by browser memory, and the output is not OCR text.

For related workflows, try OCR PDF if you need text extraction, Compress PDF Online if the result is large, or PDF to JPG Converter for the reverse conversion.

Frequently Asked Questions

What image formats are supported? +
The converter accepts JPG, JPEG, and PNG files. Other image formats should be converted before using this page.
What fit modes are available? +
You can keep the original image size, fit each image onto an A4 page while keeping its ratio, or fill an A4 page.
Does this make text selectable? +
No. The output PDF contains image pages. Use OCR PDF if you need to extract text from scans or photos.
